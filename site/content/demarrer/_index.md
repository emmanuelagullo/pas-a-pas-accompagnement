---
title: "Démarrer avec Pas à Pas"
description: "Choisir où découvrir le prototype et préparer un essai fictif."
---

Commencez par [essayer Les Passerelles](../essayer/) pour découvrir le métier.
Le prototype reste réservé aux données fictives, y compris sur votre appareil.

{{< parcours mode="service" titre="Avec un service partagé" >}}
Les comptes utilisent les mêmes données depuis plusieurs appareils.
La [démonstration partagée](../essayer/#dans-la-démonstration-partagée) est jetable :
elle ne constitue pas un service pour votre établissement.

Pour préparer un hébergement, consultez [Institutions et hébergement](../dsi/).
Les droits professionnels et le cloisonnement entre structures restent à définir
avant toute utilisation réelle.
{{< /parcours >}}

{{< parcours mode="appareil" titre="Sur cet appareil" >}}
La PWA fonctionne dans votre navigateur ; un programme existe pour Linux et Windows.
Les données restent propres à l’espace choisi, sans synchronisation entre appareils.

[Choisir une version](../essayer/) puis [faire ses premiers pas](../premiers-pas/).
Le bouton **Essayer avec Les Passerelles**, lorsqu’il est présent, ouvre un espace
distinct de votre espace habituel, avec des comptes publics.
{{< /parcours >}}

Consultez le [guide pratique](../guide/) et les [accès réellement proposés](../roles/).
