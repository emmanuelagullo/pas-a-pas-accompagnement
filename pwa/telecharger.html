Essayer Pas à Pas — Accompagnement

Prototype sur données fictives uniquement. Il permet de créer et consulter des personnes ; les ménages et accompagnements sont disponibles avec attribution explicite des droits ; les repas sont disponibles avec les droits CHRS2 ; les hébergements sont disponibles avec les droits CHRS3.

Ouvrir l’application dans ce navigateur — les données restent sur cet appareil. Pensez à conserver vos sauvegardes hors de l’appareil. Chromium est le périmètre qualifié par les bancs automatisés ; les autres navigateurs restent à vérifier.

Consulter les versions et télécharger un programme. Les fichiers n’apparaissent qu’après publication explicite d’une release.

Windows x64 : utiliser PasAPasAccompagnement-Setup-<version>-x64.exe lorsqu’il est joint à la release. L’assistant installe le programme et son raccourci ; la désinstallation conserve les données. Le ZIP portable reste disponible : extraire puis lancer PasAPasAccompagnement.exe. WebView2 doit être installé.

Linux : l’archive cible Ubuntu 24.04 x86-64 avec GTK/WebKitGTK. Extraire puis lancer PasAPasAccompagnement. La compatibilité avec toutes les distributions n’est pas garantie.

Chaque programme prépare son propre espace et demande de créer un compte. Aucun identifiant public n’y est installé. Ne pas effacer le dossier de données lors d’une mise à jour.
